Read the Docs
-------------

.. image:: /_static/img/readthedocs-logo.svg
   :alt: Read the Docs logo
   :target: https://about.readthedocs.com/
   :class: plain topo-project-logo

`Read the Docs <https://about.readthedocs.com/>`_ is documentation hosting, and the standard place Python projects host their docs.
I helped create it in 2010 as a Django Dash project,
and it has been my day job since 2014.
Our :doc:`2025 vision </blog/2025/jan/14/an-updated-vision-for-read-the-docs>`
is about building more support for other documentation tools,
and better UX for documentation authors and readers.

Write the Docs
--------------

.. image:: /_static/img/writethedocs-logo.svg
   :alt: Write the Docs logo
   :target: https://www.writethedocs.org/
   :class: plain topo-project-logo

`Write the Docs <https://www.writethedocs.org/>`_ is a community for people who care about documentation,
with conferences, meetups, a Slack, and a newsletter.
I helped start it, and I chair the Portland conference.

EthicalAds
----------

.. image:: /_static/img/projects/ethicalads-logo.svg
   :alt: EthicalAds logo
   :target: https://www.ethicalads.io/
   :class: plain topo-project-logo

`EthicalAds <https://www.ethicalads.io/>`_ is a privacy-first ad network for developers,
and it helps fund Read the Docs.
I helped create it.
I've written about where it fits in :doc:`funding open source </blog/2024/nov/1/ai-search-should-sustain-open-source>`.

Python Software Foundation
--------------------------

.. image:: /_static/img/projects/python-logo.svg
   :alt: Python logo
   :target: https://www.python.org/psf-landing/
   :class: plain topo-project-logo

I'm a `PSF <https://www.python.org/psf-landing/>`_ Fellow.
I served on the board from 2017 to 2020,
and chaired its Funding Working Group.
There I helped get the Mozilla Open Source Support (MOSS) grant
that kickstarted the PSF's Developer in Residence program.
