My home on the web
==================

I'm Eric. I build documentation tools and communities, and otherwise spend time outside.

I co-founded `Read the Docs <https://about.readthedocs.com/>`_,
`Write the Docs <https://www.writethedocs.org>`_,
`PyCascades <https://www.pycascades.com/>`_,
and `EthicalAds <https://www.ethicalads.io/>`_.
I write here about documentation, open source, and the communities around them,
and about the trails in between.
`Subscribe by email <https://ericholscher.substack.com/>`_ to get new posts.
